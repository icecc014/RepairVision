# RepairVision — 校园维修工单智能调度与 2D/3D 混合可视化系统

毕业设计项目。实现「宿管报修 → 智能派单 → 工人维修 → 完工反馈 → 数据看板」的完整闭环，并在此基础上提供校园区域总平面图（区域概览）、楼宇 2D/3D 可视化与**空间感知**的派单算法。

- 当前版本：**V9（统一入口 · 公网穿透 · 会话安全 · 移动自适应）**；已打标签的最新版本为 **`v6.0`**（V7 / V8 / V9 尚未打标签）
- V7 / V8 / V9 的完整任务书与验收结论见 `AGENTS/18`～`AGENTS/27`
- 历史标签：`v4.8` → `v5.1` → `v5.2` → `v5.3` → `v5.4` → **`v5.0`（V5 正式完成）** → **`v6.0`**

## 快速启动

```bash
# 1. 复制环境变量（首次）
copy .env.example .env   # Windows
cp .env.example .env     # Linux/macOS

# 2. 修改 .env 中的 MYSQL_ROOT_PASSWORD / JWT_SECRET

# 3. 一键启动（自动构建 8 个容器并初始化种子数据）
./scripts/up.ps1         # Windows PowerShell
docker compose up -d --build
```

启动后访问：

- 统一入口（V9 起推荐）：http://localhost:8080/ → 302 → `/login/` 统一登录页，登录后按角色自动跳转
- PC 管理端：http://localhost:8080/admin/（role=1）
- 移动端：http://localhost:8080/m/
  - 宿管入口：http://localhost:8080/m/dorm（role=3）
  - 工人入口：http://localhost:8080/m/worker（role=2）
- 公共报修（免登录）：http://localhost:8080/report → `/m/report`
- 统一入口一键验收：`./scripts/check-entry.ps1 -CheckWs`（本地 / 局域网 / 穿透地址通用）

> 登录态：统一登录页一次登录后三端共享（`rv_token` / `rv_user` / `rv_role`）；移动端标签页仍优先使用 sessionStorage 本标签页身份，不同角色可分别开标签页互不影响。

## 页面入口

### 统一登录页 `/login/`（V9）

- 入口：`/` 与 `/login` 均 302 → `/login/`；纯静态页（HTML + CSS + 原生 JS，**零新增依赖**）
- 按角色跳转：`role=1 → /admin/`、`role=2 → /m/worker`、`role=3 → /m/dorm`；其他角色提示不支持并清理登录态
- 演示账号一键填充（宿管 / 水工 / 电工）；**管理员账号不在页面提示**（V9.4 公网暴露收敛）
- 已登录时显示「进入系统 / 切换账号」，不会自动跳转造成死循环
- 两端「退出登录」与 401/403 均回到 `/login/`，并清理共享登录态
- 底部「我要报修（无需登录）」→ `/report`

### PC 管理端 `/admin/`

- 工单总览（派单评分、手动派单/改派、标记外援、锁定、优先级、代完工）
- 调度看板（在岗/在途与软上限/当日产出/管辖楼栋，含积压保护线提示与恢复自动派单）
- 数据统计看板（时间窗统计、历史总量）
- 维修类型字典（类别 electric/water/masonry/wood/other + 是否自动派单）
- 派单规则配置（5 组 13 条规则可视化编辑，保存即生效）
- 人员账号管理（工种、管辖楼栋、启用/停用）
- 工人排班（白班/休息、在岗人数、工作时段设置）
- 请假审批 / 报修记录 / 权限说明
- 建筑信息管理（编码、名称、2D 坐标、布局设计器）
- 建筑可视化（楼层 2D 平面 + 3D 楼宇）
- **区域概览**（校园总平面图：只读查看模式 + 编辑模式 + 我的画布 + 备份与恢复）

### 移动端 H5 `/m/`

- 宿管：本栋工单列表 / 极简报修（只填房间号自动推导楼层，故障类型按电/水/其他分组）/ 取消未开工工单 / 消息通知
- 工人：我的工单（开工/完工，非工作时段可确认后强制开工）/ **区域概览**（可缩放拖动、点建筑看详情、点下方楼栋按钮自动定位）/ 楼栋详情（3D 查看、按类型批量完工）/ 我的班次 / 请假

## V9（统一入口 · 公网穿透 · 会话安全 · 移动自适应）



- **V9 统一入口与登录态**（V9.1 / V9.2）：`/` 与 `/login` 不再 404，收敛到统一登录页；一次登录三端共享登录态（`rv_token` / `rv_user` / `rv_role`）；退出与 401/403 统一回到 `/login/`；`scripts/check-entry.ps1` 一键验收（本地 / 局域网 / 穿透地址通用）。
- **V9 公网穿透与加固**（V9.3 / V9.4）：cpolar HTTP 隧道只暴露宿主 `8080`；WebSocket 带 token 101、无 token 401；修复穿透下 IP 限流失真（nginx realip + XFF 覆盖），限流键恢复为真实客户端 IP。
- **V9 演示与答辩材料**（V9.5）：演示前检查清单、5 分钟演示脚本、高频 Q&A、现场故障应对（见 `AGENTS/23`）；入口二维码按决定不做（免费隧道地址每日变化）。
- **V9 长期通道**（V9.6，可选）：frp + 自有域名的固定地址方案，尚未实施。
- **V9 移动自适应**（V9.7）：≤767px 侧栏转抽屉；工单总览 / 请假审批 / 报修记录 / 人员账号四页卡片化；弹窗 / 抽屉 / 表单全局窄屏适配；区域概览支持双指缩放与按下即拖（PC 支持滚轮）；编辑类操作在移动端统一提示"请在电脑端操作"。
- **V9 会话安全**（V9.8）：管理员可在人员账号编辑里设置新密码；改密后该账号**其它端旧登录态立即失效**（JWT `pwdver` + Redis 版本号 + 鉴权比对）。
- **V9 抗压与安全加固**（V9.9）：按真实 IP 限速（接口 10 r/s、登录 3 r/s）与限并发、登录失败 5 次锁 10 分钟、静态长缓存 + gzip、安全响应头与版本号隐藏、登录页不再明示口令；越权矩阵 10/10 拦截（详见 `AGENTS/26`）。
- **V9 内网穿透**：演示期采用 cpolar HTTP 隧道，只暴露宿主 `8080`（**绝不**穿透 MySQL / Redis / Kafka / Etcd）；公网地址下用 `check-entry.ps1 -BaseUrl https://xxx -CheckWs` 验收。
- 详细任务书与实测记录见 [AGENTS/21_V9统一入口与内网穿透任务书.md](AGENTS/21_V9统一入口与内网穿透任务书.md)，当前交接状态见 [AGENTS/22_交接说明书（V9进行中）.md](AGENTS/22_交接说明书（V9进行中）.md)。

## V6（规模扩展 + 区域概览工作流）

- **规模**：28 栋楼（1~26 号宿舍楼 + 过渡 1/2 栋）、10 名工人（水工 4 / 电工 3 / 泥瓦工 1 / 木工 2）、28 个宿管账号、203 张测试工单（其中已完成 183 张，按真实概率生成：每栋每天 30% 无报修 / 40% 一单 / 22% 两单 / 8% 三单）。
- **并发与管辖**：并发上限默认 8（软上限 = 并发 + 2）；管辖楼栋按工种自动分配，人员变动后自动重算。
- **区域概览「我的画布」**：把画布另存为命名模板（可覆盖/改名/删除），查看模式下选模板点「使用此模板」即可让宿管端与工人端生效。
- **只读 / 编辑模式**：默认进入只读查看模式，点「编辑画布」可选择「新建空白画布」或「加载我的画布」。
- **画布交互**：格子固定 24px 正方形（不再被压扁），画布大于视口时用拖动与缩放查看；「适应窗口」一键全览。
- **图元自定义颜色**：PC 端取色器可选预设或自定义 RGB，宿管端/工人端同步显示。
- **坐标同步**：建筑 2D 坐标随区域概览位置同步（画布左上角为原点、第四象限、建筑左上角为定位点，1 格 = 10 米）。
- **备份与恢复**：使用模板 / 恢复前自动备份当前地图，可配置保留份数（默认 5，1~50），支持「恢复某一版」。
- **两步保存**：编辑后先「保存到我的画布」，确认无误再「使用此模板」，编辑期间不影响其他端。
- **保护线口径修正**：预警 ≥ max(在岗×5, 10 单) 或 等待 > 6 小时；保护 ≥ max(在岗×10, 20 单) 暂停自动派单；等待 > 12 小时自动强制恢复，避免积压被卡住。
- **派单规则可视化**：规则注册表 5 组 13 条（评分权重 / 自动派单 / 超时提醒 / 积压保护 / 运行状态），可批量保存、补录注册规则、新增自定义规则、恢复默认、删除，保存即生效。
- **修复批次**：批量派单工种过滤（杜绝电维修派给水工）+ 全校同工种兜底；建筑编辑不再清空布局；内置标准层改为 1 号楼布局；工单时间窗改自然日（1 天 = 今天）；状态筛选改后端过滤；操作列按能力显示（手动派单/改派/标记外援）；管理员代完工；派单候选仅列「今天排班且工种匹配」的工人（轮休置灰、支持跨区支援）；工人端区域概览文字自适应、建筑信息卡不遮挡、楼栋按钮点击自动定位；删除工人端冗余柱状图。

## V5（区域概览 + 工种治理 + 双休排班 + 空间感知动态派单）

- **V5.1 区域概览**：`order_db.campus_layouts` 保存网格与图元快照；五类图元（建筑 / 道路 / 广场绿地 / 校门 / 自定义，支持跨格与自定义文字）；PC 端可放置、拖把手改尺寸、逐格碰撞检测、撤销重做；宿管端与工人端只读查看，保存后 WebSocket 广播 `campus_changed` 就地刷新；道路图元同时作为路网数据源。
- **V5.2 工种与报修类型治理**：`users.job_type`（通用 / 电工 / 水工 / 泥瓦工 / 木工）、`fault_types.category + auto_dispatch`、`orders.manual_review`；非电非水或关闭自动派单的工单跳过自动派单、进入「待管理员处置」；派单按工种过滤候选工人。
- **V5.3 双休白班排班**：`work_settings` 支持每周休 2 天（默认错峰轮休）、可配置上下午时段、允许强制开工；在岗判断 = `今日白班 ∧ 时段内 ∧ 未请假 ∧ 启用`；派单与工时解耦（非工作时段仍入队分配）。
- **V5.4 空间感知动态派单（核心）**：道路栅格化 + 建筑接最近路网节点 + Dijkstra 距离矩阵缓存；候选集「在岗 ∧ 工种匹配 ∧ 启用」；评分 **技能 40% + 路网距离 30% + 负载 30%**；动态负载惩罚（高于人均 1.2 倍扣分）、取消并发硬上限（软槽位）；双阈值保护（预警 / 保护暂停自动派单 + 恢复）；事件驱动重算（1.5s 防抖 + 60s 兜底）；调度看板展示班次、在岗、在途/软上限、负载偏离、管辖楼栋。
- **V5.5 干预完善**：派单可解释性（总分与技能/距离/负载三项得分落 `dispatch_records` 并在工单详情展示）、锁定某单不参与自动调整、改优先级、手动转派、批量派单。

## 架构

```text
PC Admin ─┐
          ├─ Nginx :8080 ── /api ── order-api :8888 (HTTP)
Mobile H5 ┘                └─ /ws ── order-api :8890 (WebSocket)

order-api ── gRPC ── worker-rpc :9001 ── worker_db
         └─ gRPC ── map-rpc :9002 ── map_db
         └─ SQL ── order_db
         └─ Kafka topic operation-logs（异步操作日志）
```

数据隔离：worker_db（账号/技能/楼栋管辖）、map_db（楼宇/故障标记）、order_db（工单/派单记录/字典/规则/概览/模板/日志）。禁止跨库直连，跨库数据一律通过 RPC 获取。

## 注意事项

- `.env` 已被 gitignore，请勿提交真实密码与密钥。
- 依赖版本全部锁定，禁止随意升级/更换第三方库（详见 `AGENTS/01_项目规约.md` 白名单）。
- 楼栋删除会做工单引用保护；账号「删除」实际为停用，保留历史数据。
- 时间窗口径：1/3/7/30 天 = 自然日（含今天），三端一致。
- 派单口径：候选 = 在岗 ∧ 工种匹配 ∧ 启用；评分 = 技能 40% + 路网距离 30% + 负载 30%；并发软上限 = 并发 + 2。
- 统一入口口径（V9）：`/` 与 `/login` → 302 → `/login/`；退出登录与登录态失效一律回 `/login/`，并清理共享登录态。
- 穿透安全（V9）：只穿透宿主 `8080`，数据库 / 缓存 / MQ 端口不对外开放；演示结束立即关闭隧道；公网暴露期间演示账号（含超级管理员）等同公开，避免长时间在线。

演示数据脚本见 `scripts/demo-data.ps1`（`./scripts/demo-data.ps1 -Count 60`）；V3 验收/论文素材见 `AGENTS/07`，V5 算法素材见 `AGENTS/12`。
