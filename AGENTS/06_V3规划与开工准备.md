## 1. V3 目标

把“单发加权派单”升级为“字段完备的约束派单 + 轮休排班 + 可人工干预”，
同时补齐 4 栋演示数据、房间合法性校验、管理端调度工作台与看板、H5 详情与分页，
为论文提供可对比的调度算法实验与完整演示链路。

本阶段按 01/03 约束执行：
- 不新增白名单外依赖（批量指派算法手写 Hungarian/min-cost，不引 OR-Tools/Timefold 等库）。
- 所有 DB 变更先提交申请、备份后执行；本文件即变更申请载体。
- 每次可运行改动 `go build ./...`、两端 `npm run build` 全绿后再提交。

### worker_db.worker_schedules（新增表，V3.2 排班用）

```sql
CREATE TABLE IF NOT EXISTS worker_schedules (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  worker_id BIGINT NOT NULL,
  work_date DATE NOT NULL,
  shift_type VARCHAR(20) NOT NULL DEFAULT 'DAY'
    COMMENT 'DAY全天班 MORNING午班 AFTERNOON晚班 OFF休息',
  note VARCHAR(100),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_worker_date (worker_id, work_date),
  KEY idx_date (work_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```
