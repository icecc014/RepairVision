## 2. 各阶段要点

**V9.1 / V9.2 入口与登录态**：新增纯静态统一登录页（零依赖）；登录后按角色跳转（1→`/admin/`、2→`/m/worker`、3→`/m/dorm`）；共享键 `rv_token/rv_user/rv_role`，移动端 sessionStorage 优先 + localStorage 兜底。

**V9.3 / V9.4 穿透与公网加固**：cpolar HTTP 隧道只暴露宿主 `8080`（DB/Redis/Kafka/Etcd 绝不穿透）；实测 WebSocket 带 token 101、无 token 401；修复「穿透下 IP 限流退化为全局」——nginx realip + XFF 覆盖，限流键恢复为真实客户端 IP，并实测伪造 XFF 已无法带偏。

**V9.7 移动自适应**：≤767px 侧栏转抽屉；工单总览/请假审批/报修记录/人员账号四页改卡片列表；全局弹窗/抽屉/表单适配（内联固定宽度一律让位视口）；看板、统计卡、规则页、画布页、3D 卡片逐页栅格降级；区域概览支持**双指缩放**与**按下即拖**（PC 支持滚轮），编辑类操作在移动端统一提示「请在电脑端操作」；建筑可视化楼层切片修复（此前被 `overflow:hidden` 裁掉，2D/3D 都看不到楼层按钮）。

**V9.8 会话安全**：管理员可在「人员账号 → 编辑」直接设新密码；改密后该账号在**其它端的旧 token 立即失效**（JWT `pwdver` + Redis 版本号 + 鉴权比对，失败开放不锁死全站）；实测旧 token→401、新密码登录→200。

**V9.9 抗压与安全**：nginx 按真实 IP 限速（接口 10 r/s、登录 3 r/s）与限并发、静态长缓存、gzip；登录失败 5 次锁 10 分钟；安全响应头与版本号隐藏；登录页不再明示口令；越权矩阵 10/10 拦截；依赖漏洞结论与不可达原因见 `25`/`26`。
