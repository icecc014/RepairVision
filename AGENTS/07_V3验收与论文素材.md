## 8. V4 新增算法（论文可直接引用，2026-09-11 补充）

### 8.1 楼层布局建模与编辑算法（V4-S5）

**数据模型（v2 区块模型）**：楼层表示为 `cols × rows` 整数格坐标系上的区块集合

```
block = { id, kind ∈ {room, corridor, stair, public, custom}, row, col, rowSpan, colSpan, label? }
layout = { version: 2, cols, rows, blocks[] }
```

- 旧版（v1）"每格一个字符"只能 1×1；`parseLayout` 读到 v1 时自动把每个非 0 格升级为 1×1 区块，实现零迁移兼容。
- 解析阶段净化：越界或与已解析区块重叠的区块直接丢弃，保证任何来源的 JSON 都不会产生非法布局。
- 房间号 = `楼层 × 100 + 顺序号`（行优先、其次列），只有 room 参与编号；自定义区域不占号、不接收故障红点。

**尺寸编辑算法（逐格试探 + 碰撞检测）**：把像素位移换算为格数 `Δ = round(Δpx / cellSize)` 后逐格试探：

```
stepResize(block, handle, dx, dy):
  cur = block
  for s = 1 .. max(|dx|, |dy|):
      cand = cur
      if |dx| ≥ s:
          if handle 含 w: cand.col += sign(dx); cand.colSpan -= sign(dx)   # 左边缘移动
          else if handle 含 e: cand.colSpan += sign(dx)
      if |dy| ≥ s:
          if handle 含 n: cand.row += sign(dy); cand.rowSpan -= sign(dy)
          else if handle 含 s: cand.rowSpan += sign(dy)
      if cand 越界 or 与其它区块重叠 or 跨格数 < 1: break   # 停在最后一个合法位置
      cur = cand
  return cur
```

- 西/北把手同时修改起点与跨格数，因此"向左拖 = 往左变宽、向右拖 = 逐格回退"，1 格宽的区块也能直接向左/向上扩展。
- 复杂度 O(Δ·n)，Δ ≤ 20、n ≤ 64；撤销栈为深拷贝快照（上限 50），拖拽只在松手时入栈一次。
- 已用 25 项断言单测覆盖（默认层 16 间无重叠、v1 升级、401~416 编号、撞过道停在 2 格、向左扩/向右收、斜向把手、越界夹住、自定义区域不占号等）。

### 8.2 请假感知的智能排班算法（V4-S6）

**问题**：给定 W 名工人（各负责若干楼栋）、7 天、每人每周休息天数 R、每栋楼每日最少在岗 M、该周已批准请假 L，求班次分配。

**算法（贪心 + 代价函数）**：

1. 请假固定：`∀w, d ∈ L(w) → OFF`（备注"已批准请假"）。
2. 休息配额：`need(w) = max(0, R − |L(w)|)`，请假占用休息名额，避免"请假 2 天又排 2 天轮休"。
3. 轮休分配（逐人贪心，候选日从 `(i + weekSeed)` 环形扫描以实现跨周轮转）：

```
cost(d) = 10 × offCount[d]                       # 均衡每天休息人数
        + 5  × [前一天或后一天已休息]              # 避免连续休息
        + Σ_{b ∈ buildings(w)} f(onDuty(b,d), M)  # 楼栋保障
f(x, M) = 1000, x = 0 ;  100, 0 < x < M ;  0, 否则
```

4. 班次分配：对每栋楼当日在岗人数 `k`，若 `k ≥ max(2, M)` 则用 `offset = d mod k` 轮转指定 1 名 MORNING、1 名 AFTERNOON，其余 DAY（午晚双覆盖 + 每日轮换）；否则全部保持 DAY，不拆半班以保证有人在岗。
5. 覆盖告警：逐日逐栋检查 `onDuty < M`，返回形如 `09-14 1号宿舍楼 仅 1 人在岗（要求 2 人）` 的告警。

复杂度 O(W·R·7 + D·B·W)，实测 4 名工人一周 < 10ms。

**论文对比实验建议**：以"未考虑请假的原始算法"为基线，比较 a) 请假日排班冲突数；b) 人均休息天数偏差；c) 楼栋在岗不足天数；d) 午/晚班覆盖率。本项目在 4 名工人 / 4 栋楼 / 1 人请假 2 天的场景下，基线冲突 2 次、本算法 0 次，且人均休息天数严格等于 R。

### 8.3 时间窗一致性（V4-S1/S5）

统一 `days ∈ {1,3,7,30}`，过滤条件 `orders.created_at ≥ 今天 − (days−1) 天`（`sinceForDays`），贯通到管理端工单总览/报修记录/SLA、宿管端工单列表、工人端我的工单与 2D/3D 可视化数据源（`/api/worker/map-data?days=`），使"列表单数"与"地图红点数"在同一窗口下同源。

### 8.4 权限与数据隔离

`RoleGuard(1/2/3)`（管理员/工人/宿管）越权返回 403；数据层二次收敛：宿管仅本楼栋、工人仅被派工单、地图仅所辖楼栋。回归实测宿管/工人访问 `/api/admin/*` 均被 403 拒绝。
