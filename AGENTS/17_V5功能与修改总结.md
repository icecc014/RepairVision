### 1.2 V5.2 工种与报修类型治理

- 数据：`users.job_type`（0 通用 / 1 电工 / 2 水工，V6 扩展 3 泥瓦工 / 4 木工）、
  `fault_types.category`（electric / water / masonry / wood / other）+ `auto_dispatch`、`orders.manual_review`。
- 建单判定：类别为 `other` 或该类型关闭自动派单 → `manual_review = 1`，**跳过自动派单**，进入「待管理员处置」。
- 派单工种过滤：`jobTypeAllowed()` —— 电工只接电、水工只接水、泥瓦/木工各归其位，通用工人可接任意类别。
- 管理员干预：手动派单 / 协商指派、标记外援（`orders.external_mark`）、锁定、优先级、改派。
- 前端：人员账号管理加工种下拉；维修类型字典加「类别 + 是否自动派单」；工单总览对「待管理员处置」高亮。

### 1.3 V5.3 双休白班排班

- 数据：`worker_db.work_settings`（每周休息 2 天、错峰轮休 / 固定休息日、上午与下午工作时段、是否允许强制开工）。
- 排班生成重写为「白班 / 休息」二选一，默认双休错峰；请假 / 调班 / 代录 / 撤销闭环。
- **在岗判断**：今日白班 ∧ 处于工作时段 ∧ 未请假 ∧ 账号启用。
- **派单与工时解耦**：非工作时段工单照常进入队列并被分配；工人开工时若不是工作时段，前端提示后可用 `force` 强制开工（后端默认 409 拦截）。
- 页面：PC 排班页显示白班/休息/请假统计与当前在岗人数；派单规则页可配置工作时段。

### 1.4 V5.4 空间感知的动态派单（核心）

- 由区域概览道路图元构建栅格路网，建筑接入最近道路节点，用 Dijkstra 预计算**建筑间路网距离矩阵**并缓存。
- 候选集：`在岗 ∧ 工种匹配 ∧ 账号启用 ∧ 未请假`。
- 评分：`总分 = 技能匹配 40% + 路网距离 30% + 在途负载 30%`（权重可配置）。
- **动态负载均衡**：人均负载 = 在途工时 / 在岗人数；高于人均 1.2 倍时按超出比例施加惩罚，**取消并发硬上限**（软上限 = 并发上限 + 2）。
- **双阈值保护**：
  - 预警线：待派 ≥ max(在岗×倍数, 绝对单量) 或 最长等待 > 预警时长 → 看板提醒；
  - 保护线：待派 ≥ max(在岗×倍数, 绝对单量) → **暂停自动派单**转人工处置；积压回落或等待超时自动恢复，也可手动「恢复自动派单」（恢复即触发一次重算）。
- 事件驱动重算（新工单 / 完工 / 上下班 / 请假 / 调班 / 手动调整，1.5 秒防抖）+ 60 秒兜底扫描。
- 干预能力：手动转派、改优先级、锁定某单不参与自动调整、批量派单。
- 调度看板：每名工人的班次、当前在岗、在途/软上限、当日产出、管辖楼栋、暂停/可派状态。

### 1.5 V5.5 干预完善 + 回归 + 文档

- 派单可解释性：工单详情展示总分与技能/距离/负载三项得分，派单记录落 `dispatch_records`。
- 文档：算法建模与实验设计（`12`）、UI 与体验修复任务书（`13`）、规模扩展计划（`14`）。

## 2. 后续 V6.x 增量（同属本次发布）

### 2.1 V6 规模扩展（更贴近真实校园）

- 并发上限默认 8；楼栋 **16 → 26 栋**（1~16 号宿舍楼 + 17~26 号教学楼），楼栋 ID 与编码一一对应。
- 工人 **10 名**：水工 4（water1~4）、电工 3（elec1~3）、泥瓦工 1（mason1）、木工 2（wood1~2），覆盖 4 类工种。
- 宿管 **26 位**（dorm1~dorm26 各绑定 1 栋），含 worker 服务启动种子。
- 管辖楼栋**自动分配**（新增/减少工人时自动重算），并补充人工楼栋列表。
- 测试工单按真实概率重造（每栋每天约 30% 无报修 / 40% 一单 / 22% 两单 / 8% 三单，共约 200 单），工种错配 0。

### 2.2 V6.1 区域概览画布模板 + 只读/编辑模式

- 新表 `campus_layout_templates`（我的画布）：保存 / 加载 / 使用此模板 / 改名 / 删除；
  `campus_layouts` 仍是"当前生效地图"，宿管端与工人端接口零改动即可看到。
- 默认进入**只读查看模式**，点「编辑画布」可选择「新建空白画布」或「加载我的画布」。
- 画布格子固定 24px **正方形**，画布大于视口时用拖动 / 缩放查看；「适应窗口」一键全览。
- 图元支持**自定义 RGB 颜色**（PC 取色器 + 宿管端/工人端同步填色）。
- 建筑 2D 坐标与画布位置同步（画布左上角为原点、第四象限、建筑左上角为定位点，1 格 = 10 米）。

### 2.3 V6.2 备份与恢复 + 两步保存

- 新表 `sys_settings`（通用键值配置），键 `campus_backup_keep`（默认保留 5 份，范围 1~50）。
- 接口：备份列表 / 立即备份当前地图 / 恢复某一版 / 修改保留份数；每次「使用此模板 / 恢复某一版」前自动备份当前地图。
- 保存流程改为两步：**先「保存到我的画布」，再「使用此模板」**；编辑期间的改动不会影响其他端。

### 2.4 V6.3 保护线口径修正 + 派单规则可视化

- 保护线**只看待派单量**（等待时长只用于预警与强制恢复），默认阈值放宽为
  预警 ≥ max(在岗×5, 10 单) 或 等待 > 6 小时；保护 ≥ max(在岗×10, 20 单)；
  暂停期间等待 > 12 小时自动强制恢复，避免"最该派出去的积压被卡住"。
- 新增**规则注册表**：5 组 13 条规则（评分权重 / 自动派单 / 超时提醒 / 积压保护 / 运行状态只读），
  支持批量保存、新增（注册补录或自定义）、恢复默认、删除自定义；保存即生效，无需重启。
- 前端「派单规则配置」页重做为可视化编辑表单；调度看板顶部增加保护线横幅与「恢复自动派单」。

### 2.5 修复批次（本阶段实测发现并解决）

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 电维修被派给水工 | 兜底扫描 / 批量派单路径没有工种过滤 | 候选与成本矩阵都加 `jobTypeAllowed`；楼栋内无同工种在岗工人时回退「全校同工种在岗池」 |
| 改个楼栋名字布局就没了 | 建筑编辑未传 `layoutJson`，后端写空串 | 空值 = 沿用原布局，清空需显式传哨兵 `__DEFAULT__` |
| 内置标准层不好看 | 硬编码模板 | 用脚本把 1 号楼自定义布局生成双端共享常量（7×10、16 房） |
| 工人端小图元没有文字 | 放不下就不画 | 按建筑框自适应字号，必要时缩短为前 4/3/2/1 字，保证"每栋都有字" |
| 信息卡遮挡被定位的楼栋 | 卡片浮在地图上 | 卡片移到地图下方固定区域，定位时把建筑滚到视口中央 |
| 工人端柱状图挡视线 | 与区域概览重复 | 删除 2D 柱状图，只保留楼栋按钮（点击即定位） |
| 演示时要逐个登录工人账号 | 无管理员完工入口 | 新增 `POST /api/admin/orders/:id/complete` 与工单总览「完工」按钮 |
| 选「1 天」查不到当天工单 | 时间窗按"当前时刻往前推" | 改为自然日：N 天 = 从 (N-1) 天前 00:00 起（含今天） |
| 「待派单」筛选漏单 | 前端只在当前页 20 条里过滤 | 状态筛选交给后端，分页/总数/筛选一致 |
| 某单操作列没有按钮 | 脏数据（无工人却是维修中）导致条件全不匹配 | 修正 8 条脏数据 + 操作列改按能力显示（手动派单/改派/标记外援），去掉占位「—」 |
| 改派候选里有休息的人 | 只按"是否管辖该楼栋"筛 | 新增可派工人接口：仅列**今天排班且工种匹配**的工人，轮休/请假置灰并说明原因，支持跨区支援 |

## 5. 关键口径（答辩常被问的点）

1. **时间窗**：1/3/7/30 天 = 自然日，含今天（`N 天 = 从 (N-1) 天前 00:00 起`），三端一致。
2. **并发**：默认上限 8，软上限 = 上限 + 2；超过不拒派，只在评分中施加动态负载惩罚。
3. **保护线**：只看待派单量（绝对单量 + 人均倍数取较大者）；等待时长用于预警与强制恢复。
4. **在岗**：今日白班 ∧ 时段内 ∧ 未请假 ∧ 启用；手动派单候选放宽为"今天排班且工种匹配"。
5. **距离**：优先路网最短路（Dijkstra），没有路网数据时回退欧氏距离，权重可配置。

## 6. 实测记录（节选）

- 派单正确性：全库工单工种错配 **0**（电 54 → 电工、水 42 → 水工、泥瓦 13、木 9）。
- 保护线自愈：日志 `dispatch guard auto resumed: pending=3 onDuty=0 waitMinutes=651` → 下一次扫描 `dispatched=3 remained=0`。
- 时间窗：`1 天` 从 0 条修正为 29 条（当天全部工单）。
- 区域概览：画布 100×80 格、145 个图元；工人端 94/94 建筑均有文字；点楼栋按钮定位后 `zoom 250%`、容器 `scrollLeft 144`。
- 派单候选：某单可选 7 人（本楼栋 2 + 跨区支援 5），轮休 3 人置灰并给出原因。
