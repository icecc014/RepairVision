# 08_V4_UI设计规划.md（2026-09-10 新增）

> V4 以 **UI 风格设计** 为主线：柔和渐变、玻璃拟态、亲和友好的视觉与微交互。
> 参考文件：`css/颜色.html`（16 色柔和渐变板）、`css/样式.html`（玻璃拟态组件与特效）、
> `css/样式推荐.md`（120 个统一类名的常用 CSS 组件）。
> 开发分支：feature/v4（从 V3 结项基线 main 拉出）。

## 1. V4 目标与原则

1. 全站统一：PC 管理端 + H5（宿管/工人）共用一套设计令牌，主题一致。
2. 柔和渐变：低饱和、透明渐变的“雾感”配色，避免刺眼纯色与重阴影。
3. 玻璃拟态：半透明白底 + 背景模糊 + 白色描边 + 柔和投影。
4. 亲和交互：悬停抬升、聚焦光晕、未读脉冲、骨架微光、入场淡入。
5. 零新增依赖：仅用 CSS 变量与自定义样式覆盖 Element Plus / Vant，不引入白名单外库。
6. 可用性优先：保证对比度、暗光可读、支持 `prefers-reduced-motion` 降级、移动端控制模糊层数量。

## 2. 设计令牌（Design Tokens）

### 2.1 页面背景（取自 样式.html）

```css
background: linear-gradient(120deg, #e0edfa, #e9e3f8, #f8e6ec);
```

移动端可叠加一层柔和光斑（径向渐变），PC 端内容区保持低对比雾面。

### 2.2 主色与语义色

| 语义 | 名称 | 令牌（CSS 变量） |
| --- | --- | --- |
| 主色 | 晴空雾蓝 | `--rv-primary-grad: linear-gradient(135deg, rgba(200,230,255,.75), rgba(180,210,245,.65))`；实色 `#3478f6` |
| 辅助 | 矢车菊浅蓝 | `linear-gradient(135deg, rgba(214,236,252,.71), rgba(190,218,240,.61))` |
| 成功 | 薄荷水绿 | `linear-gradient(135deg, rgba(210,245,236,.73), rgba(184,232,218,.63))`；实色 `#22b573` |
| 警告 | 蜜桃暖橙 | `linear-gradient(135deg, rgba(255,226,204,.75), rgba(252,208,174,.65))` |
| 危险 | 豆沙柔粉 | `linear-gradient(135deg, rgba(248,214,222,.74), rgba(238,192,204,.64))`；实色 `#e11d48`（柔化） |
| 中性 | 鼠尾草灰绿 / 灰茶棕 | 用于次级卡片、说明面板 |
| 强调 | 淡长春紫 / 鸢尾灰紫 | 用于派单/排班类模块 |

16 色板全部保留为 `--rv-palette-1..16`，按模块分色（不重复、不刺眼）。

### 2.3 玻璃拟态参数（取自 样式.html）

```css
--rv-glass-bg: rgba(255,255,255,.45);
--rv-glass-border: 1px solid rgba(255,255,255,.55);
--rv-glass-blur: blur(12px);
--rv-glass-shadow: 0 8px 24px rgba(0,0,0,.06);
--rv-glass-shadow-hover: 0 14px 32px rgba(0,0,0,.09);
```

### 2.4 形状与节奏

- 圆角：卡片 18px、控件 12px、胶囊 999px；
- 间距：8 / 12 / 16 / 20 / 24；
- 字体：系统字体栈；标题 600-800，正文 13-14，辅助 12；
- 动效时长：150ms（点击）/ 300ms（悬停与切换）/ 1400ms（骨架微光）。

## 3. 组件风格规范

| 组件 | 规范 |
| --- | --- |
| 按钮 | 主按钮=渐变（雾蓝→薄荷）；次按钮=玻璃底；危险=柔粉渐变；悬停抬升 2px + 阴影 |
| 卡片 | 玻璃卡片：半透明白 + blur + 白描边 + 18px 圆角；悬停抬升 4px |
| 输入框 | 玻璃输入：`rgba(255,255,255,.35)` + blur；聚焦白底 0.55 + 雾蓝光晕 |
| 标签/徽章 | 胶囊形；状态色取自语义渐变（待派=暖橙、维修中=雾蓝、完成=薄荷、取消=中性） |
| 表格 | 透明表头 + 极浅斑马纹；行悬停浅雾蓝；圆角容器 |
| 统计卡 | 数字大号加粗；不同模块用不同柔和渐变底（16 色板分配） |
| 消息/时间线 | 未读圆点 + 玻璃列表项；未读脉冲动画 |
| 空状态/加载 | 柔和插画底 + shimmer 骨架；错误态使用柔粉而非大红 |
| FAB/浮动 | 渐变底 + 悬浮阴影 + 点击回弹 |
| 抽屉/弹层 | 玻璃背景 + 圆角 + 淡入上滑 |
| 分页/分段控件 | 胶囊底 + 渐变选中态 |

## 4. V4 阶段任务

### V4.0 设计令牌与主题底座

- 新增 `frontend/*/src/styles/theme.css`：CSS 变量（色板/渐变/玻璃/圆角/阴影/动效）、全局背景、滚动条、字体层级。
- Element Plus 主题覆盖（主色、成功/警告/危险、圆角、卡片、按钮、输入、表格、标签、对话框、抽屉、分页）。
- Vant 主题覆盖（主色、按钮、单元格、弹层、标签、Toast、Dialog）。
- 动效 keyframes：`fadeUp` / `shimmer` / `pulse` / `float`；支持 `prefers-reduced-motion`。
- 验收：两端全局背景与主色生效，登录页、主布局、基础控件视觉统一，构建通过。

### V4.1 PC 管理端视觉升级

- AdminShell：玻璃侧边栏 + 渐变品牌区 + 菜单胶囊激活态 + 玻璃顶栏 + 消息铃铛样式。
- 页面：工单总览、调度看板、数据统计、SLA、排班、请假审批、用户、楼栋、日志、可视化。
- 表格/筛选/分页/对话框/抽屉/标签统一玻璃卡片风格；统计卡按模块分配 16 色渐变。
- 图表/进度/趋势线使用柔和色板，超时告警用柔粉。
- 验收：全部 PC 页面无硬编码旧配色，视觉一致，交互无回归。

### V4.2 H5（宿管 + 工人）视觉升级

- 登录页：全屏渐变背景 + 玻璃登录卡 + 品牌光斑。
- 宿管：统计卡渐变、筛选胶囊、工单玻璃卡片、渐变 FAB、报修弹层、详情/评价弹层。
- 工人：工单卡片、模式标签页（工单/地图/班次/请假）、今日任务、开工/完工渐变按钮、故障解释卡。
- 班次/请假/通知中心：状态徽章、时间线、未读脉冲统一。
- 验收：移动端各页视觉统一，触控区域不小于 44px，滚动流畅。

### V4.3 2D/3D 可视化配色与特效

- 2D 平面：普通房间=雾蓝、故障房间=柔粉 + 红点脉冲、走廊/楼梯/公共区=中性雾感；故障解释卡玻璃化。
- 3D 楼宇：房间材质改用柔和色板；故障点脉冲发光；透视/楼层筛选按钮玻璃化；背景渐变。
- 验收：2D/3D 与整体主题一致，性能不下降（低端机降级策略保留）。

### V4.4 动效与微交互

- 页面/卡片入场 `fadeUp` + 列表 stagger；按钮 hover 抬升、按下回弹。
- 输入聚焦光晕；骨架 shimmer；未读/故障点 pulse；FAB 悬浮。
- 支持减弱动效；移动端限制 blur 层数，避免掉帧。

## 6. 风险与约束

1. 不新增依赖：仅 CSS 与主题变量覆盖。
2. 性能：`backdrop-filter` 在移动端限制使用层数（列表项内部不叠加多层模糊）。
3. 对比度：正文与背景对比度 ≥ 4.5:1，避免浅色文字压在浅色渐变上。
4. 动效可关闭：`@media (prefers-reduced-motion: reduce)` 时禁用位移与脉冲。
5. 功能不回退：每阶段结束必须 `go build` + 两端 `npm run build` 通过并容器重建验证。
