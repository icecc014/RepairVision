## 1. 已实施的加固（含验证证据）

| # | 加固项 | 实现 | 实测证据 |
| :---: | :--- | :--- | :--- |
| 1 | **安全响应头 + 隐藏版本号** | `nginx.conf`：`server_tokens off`、`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy` | 响应头实测返回以上字段；`Server: nginx`（无版本号） |
| 2 | **按真实 IP 限速** | `limit_req_zone`：`/api/` 10 r/s（burst 20）、`/api/login` 3 r/s（burst 10）；限速状态码 429 | 连打 40 次 `/api/public/buildings` → **31×200 + 9×429** |
| 3 | **按 IP 限并发** | `limit_conn_zone`：接口 30、登录 10 | 已生效（验收脚本正常通过，未误伤） |
| 4 | **登录失败限次（防爆破）** | `loginlogic.go`：同账号 10 分钟内失败 5 次 → 锁定，成功即清除；缓存不可用时放行 | 连打 6 次错误口令 → 前 5 次 401、**第 6 次 429**；正常账号登录 200 |
| 5 | **改密即踢下线（方案 A2）** | JWT `pwdver` claim + Redis 版本号 + `RoleGuard` 比对；改密递增 | 旧 token 改密后 → **401**；新密码登录 → 200（详见 AGENTS/25） |
| 6 | **静态资源长缓存 + gzip** | 带指纹资源 `max-age=2592000, immutable`；文本类 gzip | `Cache-Control` 实测返回；`Content-Encoding: gzip` 实测返回（`three.module` 667KB → 约 170KB） |
| 7 | **口令提示收敛** | 统一登录页密码框/标题不再明示口令；PC、移动端登录页去掉「admin / admin123」文案 | `/login/` HTML 实测不含 `admin123`；演示胶囊一键填充**保留** |
| 8 | **操作日志脱敏** | 登录请求体 password 记为 `***` | 日志实测 `"password":"***"` |

> 运维：改 `nginx.conf` 需重建 `web`；改 `loginlogic.go` 需重建 `order-api`；阈值位置见文末。

## 4. 已知风险与建议（需决策）

| 风险 | 说明 | 建议 |
| :--- | :--- | :--- |
| **默认演示口令公开** | `seed.go` 默认 `admin123`；公网隧道开启期间等价公开 | 演示期**现场才开隧道**；若要长期在线，为 admin 单独设强口令（其余账号保持默认便于体验） |
| **`/api/public/room-orders` 可枚举** | 未登录即可按楼栋+房间查报修记录 | 收紧返回字段（只回状态与时间）或改为凭订单号查询或单独限速 |
| **axios 高危依赖告警**（30 条 CVE） | 告警集中在 **Node.js 侧**（SSRF/代理/云元数据/原型污染）；本项目两端 `baseURL: '/api'` 相对路径、浏览器端运行、无代理配置 → **不可达** | 记录并说明不可达原因；如要修补须升级 axios（违反"禁止升级依赖"红线，需专项授权 + 回归） |
| **element-plus 中危告警**（`el-link` href 校验） | 全项目检索**未使用 `el-link`** → 不可触发 | 记录即可 |
| **cpolar authtoken 曾暴露** | 出现在聊天记录中 | 到 cpolar 后台重置 |

## 5. 未覆盖项

- Go 依赖漏洞扫描（`govulncheck`）未执行：需 `go install golang.org/x/vuln/cmd/govulncheck@latest` 后分别扫三个服务（本轮按用户要求跳过）
- 容器以 root 运行：属纵深防御项，公网仅暴露 web，风险有限
- CSP 未设置：项目含内联样式与 canvas，需先评估 `default-src 'self'` + `'unsafe-inline'` 的观察期方案
