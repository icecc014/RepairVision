## 4. 已经做完的（V9.1 / V9.2 / V9.4 第一批）

1. **统一入口（V9.1）**：根路径与 `/login` 不再是 404；nginx 新增三个 location；登录页随 web 镜像发布。
2. **统一登录页**：纯静态 HTML/CSS/JS，沿用 V4 令牌（柔和渐变 + 玻璃拟态）；PC 分栏居中、手机竖屏单列；演示账号一键填充；底部「我要报修（无需登录）」→ `/report`；已登录时显示「进入系统 / 切换账号」。
3. **登录态打通（V9.2）**：登录页一次写入三类键（共享 `rv_token/rv_user/rv_role`、管理端 `rv_admin_auth/rv_admin_token`、移动端 sessionStorage），一次登录三端通用；移动端读取 sessionStorage 优先、localStorage 兜底；管理端拦截非 role=1 的登录态。
4. **统一退出与失效落点（V9.4 第一批）**：两端退出与 401/403 均回到 `/login/`，并清理共享键（避免「登录页 ↔ 工作台」反复跳转）。
5. **验收脚本**：`scripts/check-entry.ps1`，支持 `-BaseUrl`（本地/局域网/穿透地址）与 `-CheckWs`。

### 本轮修掉的两个真实缺陷

| 问题 | 根因 | 修复 |
| :--- | :--- | :--- |
| 未登录时页面同时出现「你已登录」空块与表单 | `.signed { display:flex }` 覆盖了 UA 的 `[hidden]{display:none}` | `styles.css` 增加 `[hidden]{display:none !important}` |
| 携带失效共享登录态时会在登录页与工作台间反复跳转 | 移动端 401 只清 sessionStorage；且 `startsWith('/login')` 对 `/m/login` 恒为真 | 新增 `clearAuth()` 清共享键；判断改 `endsWith('/login')`；落点统一 `/login/` |
