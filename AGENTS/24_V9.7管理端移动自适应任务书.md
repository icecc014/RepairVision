# 24_V9.7 管理端移动自适应任务书

> 归属：**V9 阶梯**（2026-09-20 用户确认并入 V9）
> 目标：让 PC 管理端在手机/平板上可用，同时**保证 ≥1024px 宽屏布局零回归**
> 相关：`21_V9统一入口与内网穿透任务书.md`、`22_交接说明书（V9进行中）.md`、`23_V9.5演示与答辩材料.md`

## 1. 为什么做（改造前实测）

- `frontend/pc-admin/src/components/AdminShell.vue` 为 `grid-template-columns: 232px 1fr` + `height: 100vh; overflow: hidden`，13 个导航项常驻左侧；390px 手机上侧栏占约 60% 宽度，内容区只剩约 158px。
- 全管理端仅 `views/LoginView.vue` 有一处 `@media (max-width: 860px)`，其余 13 个页面无任何自适应处理。
- 依赖锁死 Element Plus 2.7.5，项目红线禁止新增依赖 → 只能用现有组件 + CSS 媒体查询。

## 2. 断点与原则

| 档位 | 宽度 | 布局 |
| :--- | :--- | :--- |
| 移动 | ≤767px | 侧栏转为抽屉；顶栏压缩；内容单列 |
| 平板 | 768–1023px | 暂保持现状（后续可选优化） |
| 宽屏 | ≥1024px | **与改造前完全一致（回归基线）** |

原则：不新增依赖、不动主题令牌、不改后端接口、宽屏零回归。

## 4. V9.7.1 实施记录（2026-09-20）

改动文件：`frontend/pc-admin/src/components/AdminShell.vue`（+143 / −4）

- 侧栏加 `:class="{ 'mobile-open': navOpen }"`：≤767px 时 `position: fixed` + `translateX(-100%)`，展开动画 `cubic-bezier(0.22, 1, 0.36, 1)`
- 新增遮罩 `.nav-mask`（点按关闭）与汉堡按钮 `.nav-toggle`（宽屏 `display: none`）
- `navOpen` 随路由变化自动收起，避免切页后遮挡内容
- `height: 100vh` 之后追加 `height: 100dvh`（不支持的浏览器自动忽略）；内容区底部加 `env(safe-area-inset-bottom)`
- 移动端隐藏「管理员」标签与用户名（`.desktop-only`），退出按钮缩小
- **宽屏分支未改动**：新增样式全部位于 `@media (max-width: 767px)` 内，或默认 `display: none`

## 5. 验收标准（V9.7 整体）

- 360×800 与 390×844：无横向滚动；抽屉可开合；表格页可完成一次操作（改派 / 审批）
- 1024×800、1440×900：与改造前一致
- 触控目标 ≥44px；正文字号 ≥13px
- 手机可经局域网或 cpolar 公网地址访问 `/admin/` 并登录

## 6. 风险与注意

- `el-table` 在移动端体验差：V9.7.2 卡片化会改动较多模板，但只动前端、不动接口
- 区域概览 / 3D 是大画布交互，移动端只读可避免误操作与手势冲突
- 抽屉为手写实现（未用 `el-drawer`），避免 Element 内部样式与 scoped 样式的冲突；键盘焦点管理后续可补
